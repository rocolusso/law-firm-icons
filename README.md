# law-firm-icons

Каталог SVG-іконок для сайту юридичної компанії в Україні: 16 послуг × 10 стилів = 160 SVG (плюс 16 PNG для luxuryV3), без тексту на іконках.
Сайт зроблено на Next.js 16 (App Router), mobile first.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

Інші команди: `npm run lint`, `npm run typecheck`, `npm test`, `npm run format`.

## UI-кіт

`docs/ui-kit-luxury2.png` і `docs/ui-kit-luxuryV3.png`: листи з усіма 16 іконками.

luxuryV3 малює об’єм через SVG-освітлення (`feDiffuseLighting`, `feSpecularLighting`). Браузери це підтримують, а Figma та частина редакторів ігнорують фільтри й покажуть пласке золото. Для них поруч лежить `*_luxuryV3.png` (512 px, прозорий фон).

## Структура

- `public/icons/NN-послуга/послуга_стиль.svg`: самі іконки, по папці на кожну послугу.
- `src/features/icons/catalog.ts`: список послуг і стилів, шляхи до файлів.
- `src/app/page.tsx`: головна, сітка послуг і перемикач стилю (`/?style=luxury`).
- `src/app/icons/[slug]/page.tsx`: сторінка послуги з усіма 10 стилями, завантаження та копіювання коду.

## Стилі

outline, duotone, solid, badge, tile, luxury, luxury2 (золоте тиснення на темно-синій плитці), luxuryV3 (реалістичне золото з об’ємом), gradient, mono (`currentColor`, фарбується CSS).
Кольори: темно-синій `#14213D`, золотий `#B98B53`.

## Послуги

Податкові, митні, цивільні та господарські, сімейні та спадкові, адміністративні, банківські та фінансові, земельні, трудові, кримінальні справи; виконавче провадження; корпоративне право; юридичний супровід бізнесу; публічні закупівлі; нерухомість та будівництво; агробізнес; банкрутство та фінансова реструктуризація.

Щоб додати послугу, покладіть іконки в `public/icons/NN-slug/` і допишіть її в `SERVICES`. Тест у `catalog.test.ts` перевірить, що всі 10 файлів на місці, мають `viewBox` і не містять тексту.
