# law-firm-icons

Каталог SVG-іконок для сайту юридичної компанії в Україні: 16 послуг × 9 стилів = 144 файли, без тексту на іконках.
Сайт зроблено на Next.js 16 (App Router), mobile first.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

Інші команди: `npm run lint`, `npm run typecheck`, `npm test`, `npm run format`.

## UI-кіт

`docs/ui-kit-luxury2.png`: лист із усіма 16 іконками у стилі luxury2.

## Структура

- `public/icons/NN-послуга/послуга_стиль.svg`: самі іконки, по папці на кожну послугу.
- `src/features/icons/catalog.ts`: список послуг і стилів, шляхи до файлів.
- `src/app/page.tsx`: головна, сітка послуг і перемикач стилю (`/?style=luxury`).
- `src/app/icons/[slug]/page.tsx`: сторінка послуги з усіма 9 стилями, завантаження та копіювання коду.

## Стилі

outline, duotone, solid, badge, tile, luxury, luxury2 (золоте тиснення на темно-синій плитці), gradient, mono (`currentColor`, фарбується CSS).
Кольори: темно-синій `#14213D`, золотий `#B98B53`.

## Послуги

Податкові, митні, цивільні та господарські, сімейні та спадкові, адміністративні, банківські та фінансові, земельні, трудові, кримінальні справи; виконавче провадження; корпоративне право; юридичний супровід бізнесу; публічні закупівлі; нерухомість та будівництво; агробізнес; банкрутство та фінансова реструктуризація.

Щоб додати послугу, покладіть іконки в `public/icons/NN-slug/` і допишіть її в `SERVICES`. Тест у `catalog.test.ts` перевірить, що всі 9 файлів на місці, мають `viewBox` і не містять тексту.
